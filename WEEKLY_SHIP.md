# Weekly ship checklist

**Purpose:** real contribution graph + proof on the profile — not empty commits.

Rules: something a stranger could **review or run**. Prefer product repos under [asyncapps-hq](https://github.com/asyncapps-hq) or **one external PR**.

## Every week (pick all that apply)

- [ ] **Product:** merge or open PR on Deflake / A11yGuard / LensQA / other HQ repo (feature, fix, docs, or CI)
- [ ] **Verify:** CI green on that change (or demo still works: Deflake `npm run demo` exit `2`)
- [ ] **External (target 1×/week):** a11y, Playwright smoke, or docs PR on a public repo with recent activity
- [ ] **Proof:** if something merged upstream, add the link to [profile README merges](https://github.com/KhyFee/KhyFee#earned-open-source-selected-merges) when you next touch the profile
- [ ] **Hygiene:** no secrets in git; no synthetic co-authors; no mass spam issues

## Optional stretch

- [ ] Reply once on a GitHub Community thread with a concrete answer (Galaxy Brain path)
- [ ] Release tag / changelog note on a product when the change is user-facing
- [ ] Dev Program / Student Pack only with real eligibility docs

## Monthly

- [ ] Pin list still matches best products ([asyncapps-hq](https://github.com/asyncapps-hq) pins + personal pins)
- [ ] Drop stale open PRs or finish maintenance feedback
- [ ] Re-read Deflake README “60-second demo” — still true?

## Anti-patterns (skip)

- Empty `chore: update` only to paint green
- Follow/star farming
- Joining random orgs for logo rows
- Opening low-value duplicate issues
